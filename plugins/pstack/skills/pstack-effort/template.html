pstack routing

Role to model map

Each row is one pstack role. Pick the provider and model for each slot, then tick an effort level. Ticking a level clears the others in that slot. Clear every box to run at the session's own effort. Panel roles run one worker per slot, so you can add, remove or repeat slots. Load a preset to fill every role it names. Changed rows are marked. The block at the bottom is a ready message to paste back into Claude Code.
